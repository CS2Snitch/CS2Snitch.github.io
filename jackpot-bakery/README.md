# Jackpot Bakery v1.1.0

Jackpot Bakery is an original retro pixel-art incremental arcade game by Snitch Studio. Bake fictional crumbs through five unlockable slot-style ovens, purchase production upgrades, trigger Hot Oven streaks, earn achievements, and prestige for permanent Golden Crumbs.

## Play

Windows portable build: run Jackpot_Bakery_1.1.0_Windows_x64.exe.

Source build: install the current Node.js LTS release, extract the folder, and run Play_Jackpot_Bakery.bat.

## Version 1.1.0

- Original seamless stereo bakery theme rendered at exactly 48,000 Hz
- Independent music and sound-effect volume controls
- Responsive layouts for 640x480 through 4K, ultrawide, and high-DPI screens
- Fullscreen toggle and F11 support
- Short-height compact mode and safe scrolling
- Preserved local save key and automatic migration from v1 saves
- Keyboard and controller-friendly controls

## Gameplay

- Five themed ovens with distinct payout curves
- Manual Bake and automatic production
- Levels, auto-bakers, multipliers, combos, jackpots, and Hot Oven mode
- Offline earnings with a capped catch-up window
- Golden Crumb prestige and permanent perks
- 25 achievements and detailed lifetime statistics
- Autosave plus export/import backup

## Steam safety

The game contains fictional simulated slot mechanics but no real-money wagering, purchases, cash-out, item trading, or prizes with monetary value. Complete Steam's Content Survey accurately and describe the simulated gambling mechanic. Valve makes the final review decision.

Native Steam achievements require your Steam App ID and Steamworks SDK integration. The included browser bridge safely falls back to local achievements until that integration is added.
