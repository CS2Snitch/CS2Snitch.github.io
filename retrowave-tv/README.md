# RetroWave TV — MVP

A dependency-free prototype for a rights-first public-domain streaming service.

## Included
- Retro television styled responsive homepage
- Channel switching
- Live-program presentation
- Program guide
- Searchable on-demand library
- Admin rights-record prototype
- PWA manifest

## GitHub Pages
This project is deployed as a static subsite at `/retrowave-tv/` in the `CS2Snitch.github.io` repository.

## Add real video
In `app.js`, set `mediaUrl` for a catalog item to a media file you are legally allowed to stream. For production, use HLS + object storage/CDN rather than editing JavaScript by hand.

## Important
Do not assume a video is lawful to redistribute merely because it appears on an archive website. Verify the exact work and exact media asset/version before publishing it.
